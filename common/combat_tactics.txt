#### COMBAT TACTICS ###########################################################
#
# NOTE: tactics must start with "tactic_" in their name to work with techs.
#
# HER COMMAND MODEL
# attack_skill_level    = mechanized / armored tactical competence
# defense_skill_level   = infantry / artillery tactical competence
# planning_skill_level  = operational planning and prepared execution
# logistics_skill_level = initiative, flexibility and self-reliance
#
# Doctrine unlocks determine what an army knows; composition / reserves / terrain
# determine what is possible; traits define style; overall skill and skill_advantage
# remain general quality checks; HER subskills steer tactic selection itself.
#
# Trait integration rule:
# - professional / branch traits (panzer, mobile warfare, artillery, engineers) may
#   directly open or strongly weight relevant tactics;
# - personality traits primarily work through HER subskills and receive only small
#   direct weights when the character of the decision itself is relevant.
###############################################################################
